# Рост

Небольшое приложение для знакомства с физической подготовкой: три силовых дня со взрослым и два дня легкой активности. Русский интерфейс, подходы и повторы, план и факт по каждому подходу, отметки выполнения, журнал на устройстве и обновление расписания через JSON.

Репозиторий приложения: [dimitriyvolchenko/rost-kids](https://github.com/dimitriyvolchenko/rost-kids). Адрес опубликованного сайта доступен в Settings → Pages.

## Установка и публикация

1. Распакуйте ZIP. Все файлы приложения лежат рядом, без вложенных папок.
2. Загрузите **сами файлы**, включая `index.html`, `app.js`, `styles.css`, `program.json`, `sw.js`, `manifest.webmanifest`, значки и `install.html`, в корень отдельного репозитория. Не заменяйте файлы другого приложения.
3. В GitHub откройте **Settings → Pages → Build and deployment**.
4. **Source → Deploy from a branch**; **Branch → main** (либо реальная основная ветка); папка **/ (root)**; **Save**.
5. Дождитесь публикации и используйте адрес, показанный GitHub Pages. Для работы PWA нужен HTTPS.
6. На iPhone откройте сайт в Safari → «Поделиться» → «На экран “Домой”» → «Открывать как веб-приложение», если предлагается → «Добавить».
7. Откройте приложение с нового значка с интернетом и дождитесь загрузки плана. Начинайте вести журнал именно здесь: установленная PWA и браузер могут использовать разные хранилища.

Иллюстрированная инструкция находится в [install.html](./install.html). На Android используйте установку веб-приложения в меню Chrome; на Windows доступна обычная браузерная версия.

## Безопасный старт

Это общий пример начальной программы, а не индивидуальное медицинское назначение и не фиксированный план до 15–16 лет. Первые занятия и соответствие упражнений ребенку лучше проверить со специалистом по детской физической подготовке. При заболеваниях, ограничениях физкультуры, травмах, боли или других симптомах сначала обсудите нагрузку с врачом.

- Понедельник, среда, пятница: силовая подготовка всего тела с умеренным акцентом на ноги, под непосредственным присмотром взрослого, обученного контролировать технику.
- Вторник, четверг: знакомые танцы или прогулка и мягкая подвижность.
- В отсутствие взрослого приложение предлагает легкую альтернативу без инвентаря; боль / плохое самочувствие блокирует тренировочные отметки.
- Начальная нагрузка — собственный вес. **0 кг означает отсутствие дополнительного инвентаря, а не массу ребенка.**
- Взрослый блоковый тренажер, турник, лестница и гантель не входят в начальный план. Их пригодность, крепления, страховку и технику нужно оценить отдельно.
- Вес автоматически не повышается. Прогресс — уверенная техника, сила и удовольствие, без измерений фигуры и наказания за пропуски.

Источники и рекомендации доступны в программе и в разделе «Взрослым».

## Данные и резервные копии

Журнал хранится локально в браузере, ключ `rost.journal.v1`. Нет аккаунтов, аналитики, серверного журнала и автоматической синхронизации между устройствами. Не добавляйте личные данные ребенка в публичный репозиторий или `program.json`.

В разделе **«Взрослым»**:

- **«Скачать мои записи»** — экспорт JSON; делайте копию еженедельно и перед сменой телефона, браузера или адреса сайта.
- **«Восстановить из файла»** — перенос ранее экспортированного журнала. Проверьте подтверждение при совпадении дат; не заменяйте существующую историю случайной копией.
- **«Проверить обновления»** — получение новой версии расписания при наличии интернета.

Начатое занятие хранит снимок программы. Обновление `program.json` не должно менять его план и уже введенные результаты. Новая программа применяется к еще не начатым занятиям.

Очистка данных сайта, удаление приложения, смена браузера или автоматическое освобождение места могут удалить журнал. Кэш для офлайн-работы не заменяет резервную копию. Приложение запускается офлайн только после первого успешного открытия с сетью и сохранения ресурсов.

## Обновление program.json

Редактируйте **полный существующий** файл, сохраняйте его структуру и увеличивайте `version` при каждом изменении. Не создавайте новую программу из одного сокращенного примера ниже. Перед изменением нагрузки согласуйте ее с человеком, умеющим работать с детьми.

| Поле | Значение |
| --- | --- |
| `schemaVersion` | `1`, версия структуры данных |
| `version` | Строка версии программы, например `2026-11-17.2` |
| `days` | Семь дней; `weekday`: 0 — воскресенье, 1 — понедельник, …, 6 — суббота |
| `kind` | `strength`, `easy` или `rest` |
| `exercises` | Массив упражнений дня |
| `sets` | Число подходов |
| `reps` | Количество повторений, секунд или минут согласно `unit` |
| `unit` | `повт.`, `на сторону`, `сек.` или `мин.` |
| `loadKg` | Масса дополнительного инвентаря в кг; 0 — без него |
| `restSec` | Отдых в секундах; можно отдохнуть дольше |
| `adultRequired` | Нужен ли взрослый для этого упражнения |
| `solo` | Только легкие знакомые движения без дополнительной нагрузки |

Фрагмент **одного упражнения** для ориентира; это не полный `program.json`:

```json
{
  "id": "chair",
  "title": "Встать со стула",
  "sets": 1,
  "reps": 8,
  "unit": "повт.",
  "loadKg": 0,
  "restSec": 60,
  "cue": "Устойчивый стул у стены, плавные движения.",
  "easier": "Стул повыше; можно помогать руками.",
  "adultRequired": true
}
```

Схема верхнего уровня, **описание, не JSON для загрузки**:

```text
schemaVersion, version, title, intro,
sources: [{title, url}], guidance: [строки],
days: [{id, weekday, label, title, kind, minutes, focus, warmup,
        cooldown, exercises: [объекты упражнений]}],
solo: {id, title, kind, minutes, focus, warmup, cooldown,
       exercises: [объекты упражнений]},
progression: [строки]
```

Сохраняйте стабильные `id`. Новому упражнению нужен новый `id`; не переиспользуйте старый идентификатор с другим смыслом. Сохраняйте единицы измерения понятными и последовательными. Не включайте инвентарь в режим `solo`.

Сохраните правку в GitHub, дождитесь публикации Pages, затем откройте приложение с интернетом и нажмите **«Проверить обновления»**. При недоступной или некорректной новой программе приложение должно сохранить предыдущую корректную версию.

## Обновление интерфейса

При изменениях `index.html`, `app.js`, `styles.css` и других ресурсов обновите ревизию кэша в `sw.js`. Не меняйте ключ журнала или его структуру без миграции. Закройте все окна приложения, затем откройте с сетью. Сохраненная история не должна очищаться при обновлении.

Изменение одного `program.json` не требует переноса журнала или переустановки. Смена домена, адреса или режима запуска может создать отдельное хранилище — заранее экспортируйте записи.

## Проверка после публикации

- План отображается, дни недели соответствуют датам.
- По умолчанию взрослый не отмечен; силовой день заменяется легкой альтернативой.
- После отметки присутствия взрослого доступен силовой план; «Боль / плохо» останавливает запись.
- Факт и галочки сохраняются после закрытия и открытия.
- Экспорт скачивается, импорт проверяет структуру и совпадающие даты.
- После первого успешного открытия приложение доступно без интернета.
- Новая версия программы загружается; уже начатое занятие сохраняет прежний снимок.

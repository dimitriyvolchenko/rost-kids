Добавь «Рост» на главный экран. Взрослые обновляют программу, ребенок отмечает свой опыт и учится двигаться в комфортном темпе.

На iPhone: три простых шага

Сначала открой опубликованный сайт в Safari с интернетом. Ниже — схемы интерфейса, не снимки экрана.

1Открой сайт

Используй ссылку, которую GitHub показывает в Settings → Pages. Затем нажми «Поделиться».

2На экран «Домой»

В меню выбери «На экран “Домой”». При необходимости прокрути список действий.

3Добавь «Рост»

Включи «Открывать как веб-приложение», если этот пункт есть. Нажми «Добавить».

После установки открой «Рост» с нового значка и дождись загрузки плана. Начни вести журнал именно здесь: Safari и установленное приложение могут хранить данные отдельно.

Первое занятие

  1. Выбери дату и отметь самочувствие. При боли, головокружении или болезни — пауза и взрослый.
  2. Силовые дни доступны только со взрослым, умеющим контролировать технику. Одна — только знакомая легкая активность.
  3. Посмотри план, выполни комфортный объем, запиши факт и поставь галочку. Пустое поле факта не заменяется выдуманным результатом.

План — осторожный старт, а не назначение на пять лет. Первые занятия лучше провести со специалистом по детской физической подготовке; при заболеваниях, травмах или ограничениях сначала нужен врач. Взрослый блоковый тренажер, турник, лестница и гантель в стартовую программу не входят.

Пн, ср, пт — сила со взрослым. Вт, чт — легкая активность. В выходные — свободная игра и обычное движение. Пропуски не отрабатываем. Цель — сила, техника, уверенность и удовольствие.

Как обновлять программу

  1. В разделе «Взрослым» нажми «Скачать мои записи».
  2. В GitHub отредактируй полный файл program.json. Увеличь строку version. Сохраняй стабильные id дней и упражнений.
  3. Дождись публикации Pages. Открой приложение с интернетом и нажми «Проверить обновления». Новый план применяется к еще не начатым занятиям; начатые сохраняют снимок своего плана.
  4. При изменениях интерфейса замени соответствующие файлы, обнови ревизию кэша в sw.js, затем закрой все окна приложения и открой его снова с интернетом.
Записи живут на устройстве. Автоматической синхронизации между телефонами нет. Раз в неделю сохраняй экспорт, обязательно — перед сменой устройства, адреса сайта или очисткой браузера. Для переноса нажми «Восстановить из файла» в «Взрослым» и проверь записи за совпадающие даты.

Офлайн-запуск требует первого успешного открытия по HTTPS. Очистка данных, удаление приложения или освобождение памяти браузером могут удалить записи; кэш не является резервной копией.

Android и Windows

На Android открой сайт в Chrome, нажми меню ⋮ и выбери установку веб-приложения / добавление на главный экран. На Windows можно пользоваться прямо в браузере; если Chrome предлагает установку приложения, следуй его подсказкам.

Контрольная проверка

Сделай пробную отметку на легком дне, перезапусти приложение, проверь сохранение и экспортируй журнал. Затем проверь запуск без интернета. Пробную галочку можно снять.
